## Part 1: Algorithmic Mastery & Iterators
Moved away from standard `for` loops and embraced zero-cost abstraction iterators to solve string and array manipulation problems.

* **The Iterator Pipeline:** Mastered chaining methods to process data streams efficiently.
    * `s.chars()`: Safely breaking UTF-8 strings down into Unicode characters.
    * `.map()`: Transforming data (handling Unicode case-switching quirks with `.to_string()`).
    * `.filter()`: Using destructuring (`|&c|`) to strip references and cleanly conditionally keep or discard items.
    * `.collect()`: Reconstructing processed data back into owned `String` or `Vec` collections.
* **Vector Manipulation:** * Converting slices to owned vectors using `.to_vec()`.
    * Applying in-place mutations using `.sort()` (ascending) and reverse logic `.sort_by(|a, b| b.cmp(a))` (descending).
* **Positional Searching:** Utilized `.rev().position()` to shift coordinate frames and search arrays from right-to-left without manual index math.

---

## Part 2: Advanced Data Structures & Safety
* **HashMaps (Dictionaries):** * Imported via `std::collections::HashMap`.
    * Learned safe retrieval using `.get()` which returns an `Option` to prevent crashing on missing keys.
    * Mastered idiomatic updates using the Entry API: `map.entry(key).or_insert(value)` to conditionally write data without overwriting existing states.
* **Error Handling (`Result<T, E>`):**
    * Abandoned `try/catch` paradigms for Rust's "Errors as Values" model.
    * **Brute Force:** Used `.unwrap()` and `.expect("msg")` to intentionally panic/crash on failure during prototyping.
    * **Graceful Propagation:** Leveraged the `?` operator to safely attempt operations and automatically return errors up the call stack to be handled by the main application flow.

---

## Part 3: Project Architecture (The Module Tree)
Deconstructed how Rust compiles files and manages scope privacy.
* **Packages vs. Crates:** A Package (the folder with `Cargo.toml`) can house multiple Binary Crates (`main.rs`) but only one Library Crate (`lib.rs`).
* **The Module System:** * Understood that creating a file does *not* automatically make it a module.
    * Used the `mod` keyword in the crate root to explicitly wire files and folders into the compiler's tree.
* **Privacy & Scope:**
    * Recognized that everything in Rust is strictly private by default.
    * Used the `pub` keyword to intentionally expose internal functions and structs to outer modules.
    * Navigated the namespace using `use crate::...` (absolute) and `super::` (relative) paths.
