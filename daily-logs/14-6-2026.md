## Study: Rust Closures

### 1. What is a Closure?
An anonymous, inline function that can capture variables from its surrounding environment.
```rust
let limit = 5.0;
let is_heavy = |pkg_weight| pkg_weight > limit; // Captures `limit`
```

### 2. Syntax & Variants
Defined using vertical pipes `||` for parameters. Types and braces are optional:
```rust
let add_tax = |p| p * 1.14;                        // Shortest form
let add_tax = |p: f64| -> f64 { p * 1.14 };        // Explicit form
let log_msg = || println!("Order complete");       // No parameters
```

### 3. Closures vs. Functions
Unlike normal functions (`fn`), closures are anonymous, defined inline, and can capture variables from their outer scope.

### 4. Capturing Modes
Rust automatically chooses the cheapest capture mode:
1. **By Reference (`&T`)**: Borrows read-only. Original scope retains ownership (default).
2. **By Mutable Reference (`&mut T`)**: Modifies the captured variable.
3. **By Ownership (`move`)**: Takes full ownership (e.g., passing to other threads).
   ```rust
   std::thread::spawn(move || println!("Item: {}", name));
   ```

### 5. The Fn Traits
Categorized by how they handle captured values:
- **`Fn`**: Borrows immutably. Can be called repeatedly.
- **`FnMut`**: Borrows mutably. Can be called repeatedly.
- **`FnOnce`**: Consumes captures. Can only be called once.

### 6. Practical E-Commerce Patterns
- **Filtering**: `products.iter().filter(|p| p.in_stock)`
- **Mapping**: `prices.iter().map(|&p| p * exchange_rate)`
- **Sorting**: `products.sort_by(|a, b| a.price.partial_cmp(&b.price).unwrap())`
- **Lazy Evaluation**: `find_product().unwrap_or_else(|| create_default())`
