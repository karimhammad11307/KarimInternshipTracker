## Part 3: Deep Dive into Core Language Concepts (Chapter 3)
*   **Variables and Mutability:** Explored the physical differences between variables (immutable by default, can be explicitly marked mutable via `mut`) and true compiler constants (`const`). Reviewed **Shadowing**, a mechanism allowing developers to reuse variable names, automatically changing types and allocations without mutating underlying structures.
*   **Scalar and Compound Data Types:**
    *   *Scalars:* Mastered exact type definitions across Integers (`i8`-`i128`, `u8`-`u128`, `isize`/`usize`), Floating-Points (`f32`, `f64`), Booleans, and the Character type (`char`, representing a full 4-byte Unicode Scalar Value).
    *   *Compounds:* Analyzed fixed-size **Tuples** (combining varying distinct types into one structure) and **Arrays** (allocating flat collections of matching types directly onto fast Stack memory regions).
*   **Function Architecture:** Mapped out typed signatures. In Rust, statements perform an isolated action without returning any value, whereas **Expressions** compute a value and evaluate directly into a final result. Observed that returning data from a function block can be achieved implicitly by omitting the trailing semicolon from the final expression line.
*   **Control Flow Foundations:** Reviewed standard condition evaluating branches via `if/else` statements. Because `if` functions as an expression rather than a statement, it can be assigned directly to variables (e.g., `let number = if condition { 5 } else { 6 };`), provided both execution paths resolve to matching, homogenous types.
