## Part 2: Rust Chapter 10 - Generic Types
Explored **Generics** to eliminate code duplication and write highly abstract, reusable code.

* **The Core Concept:** Instead of writing separate functions for `i32` and `char`, use a generic type parameter `<T>` to handle multiple types dynamically.
* Generics in Enums: Realized that Rust's most powerful enums (Option<T> and Result<T, E>) are just generic enums under the hood.

* **Monomorphization** (Zero-Cost Abstraction): Generics have zero runtime performance cost. The Rust compiler physically generates separate, concrete versions of the function for the specific types used (i32, f64, etc.) in the final machine code during compilation.

## Part 3: Algorithmic Mastery & Iterators
Completely rewired my approach to loops by embracing Rust's functional Iterator pipeline for string and array manipulation.

The Iterator Pipeline:

s.chars(): Safely breaks UTF-8 strings down into Unicode characters.

.map(): Transforms data (handled Unicode case-switching quirks with .to_string()).

.filter(): Used destructuring (|&c|) to strip references and cleanly conditionally keep or discard items.

.collect(): Reconstructs processed data back into owned String or Vec collections.

Vector Manipulation:

Converted slices to owned vectors using .to_vec().

Applied in-place mutations using .sort() (ascending) and reverse logic .sort_by(|a, b| b.cmp(a)) (descending).

Positional Searching: Utilized .rev().position() to shift coordinate frames and search arrays from right-to-left without manual index math errors.
