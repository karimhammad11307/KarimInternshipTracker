# Daily Dev Log: May 13, 2026

**Focus:** Transitioning to Backend Systems Programming (Rust Fundamentals & Memory Architecture)

## Overview
Today, I focused on accelerating my onboarding for my full-stack internship by diving into Rust. The primary goal was to shift my mental model from garbage-collected environments (like Node.js/V8) to Rust’s strict, compile-time memory safety. I mapped out the foundational syntax, explored the core memory paradigms, and established a strategic learning path to quickly become productive building backend APIs.

## What I Studied & Mapped
*   **Basic Syntax & Primitives:** Mapped Rust's explicit scalar and compound types. I reviewed variable mutability (using the `mut` keyword), type casting (the `as` keyword), and how Rust handles explicit integer sizing (`i32`, `usize`, etc.) to optimize backend memory usage.
*   **Functions & Data Unpacking:** Analyzed how Rust elegantly handles multiple return values without needing complex objects. Studied Tuple creation and explicit destructuring patterns (e.g., unpacking `(123, 321)` into separate variables `a` and `b`) which is heavily used when interacting with database drivers.
*   **Memory Architecture (Ownership & Borrowing):** Deeply studied Rust's paradigm shift to prevent data races and memory leaks. Mapped the critical differences between:
    *   **Pass by Value (`Copy` trait):** How simple primitives are duplicated on the stack.
    *   **Move Semantics:** How ownership of heap-allocated data (like `String`) completely transfers to prevent dangling pointers.
    *   **Borrowing:** Explored the strict compiler rules for passing references—allowing multiple immutable readers (`&T`) OR exactly one mutable writer (`&mut T`) at any given time.
*   **Infrastructure & Deployment (Nginx):** Clarified the architectural relationship between a compiled Rust backend and web servers. Mapped how Nginx acts as the reverse proxy, load balancer, and secure "front door" for high-performance Rust web frameworks like Axum or Actix-web.
*   **Targeted Learning Strategy:** Formulated a fast-track study plan focusing on syntax muscle-memory via *Tour of Rust*, local compiler debugging via the `rustlings` CLI tool, and targeted architectural tutorials.
